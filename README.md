# quickstyle-site

Public pages for the Quick Style Dubai app, served by GitHub Pages from `main` at https://wasptechuae.github.io/quickstyle-site/.

- `/pay/return/` sends the customer from Ziina's checkout back to the app (`quickstyle://payment-return`). It never says a payment succeeded; the app checks with the server.
- `/support/` placeholder with the public WhatsApp number.

Plain HTML, no build step. Nothing secret lives here. The owner can later move these pages to quickstyle.ae.
